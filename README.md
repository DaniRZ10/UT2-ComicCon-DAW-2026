# Comic-Con DAW 2026 - 2º DAW (ILERNA)

Inscripción a la Comic-Con DAW 2026 en un único archivo (`comicon.php`), que incluye formulario POST, validación, cálculo del precio y resguardo.

## Reglas de edad

- Entrada VIP: solo para mayores de edad (18 años o más).
- Entrada Infantil: disponible hasta los 16 años

## Cómo ejecutarlo

1. Clonar el repositorio en la carpeta `htdocs` de XAMPP.
2. Arrancar Apache desde el Panel de Control de XAMPP.
3. Abrir la siguiente URL en el navegador: http://localhost/UT2-ComicCon-DAW-2026/comicon.php

Cada envío queda registrado con `error_log` (ÉXITO o FALLO) en el log de Apache de XAMPP: `C:\xampp\apache\logs\error.log` (Panel de XAMPP → Apache → Logs → Apache (error.log)).
